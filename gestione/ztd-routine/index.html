Configurazione una sola volta per browser

Per la sicurezza dei contatti, NON utilizzare l'endpoint pubblico usato dai QR. Crea una seconda app Google Apps Script separata, accessibile solo al proprietario. Copia il file ZTD_Routine_Dashboard_GitHub_PRIVATA.gs in un nuovo progetto, pubblicalo come App web · Esegui come: Me · Chi può accedere: Solo io e incolla il nuovo URL /exec qui sotto.

Il collegamento viene conservato esclusivamente nella memoria locale di questo browser; non è caricato su GitHub né inviato ad altri server. Solo Google decide chi può aprire la Web App. Configura una volta per ogni dispositivo usato.
