Macro Excel (.bas)
Sincronizzazione locale: il CRM legge le registrazioni del farming automaticamente quando cambiano. Il file Excel sul computer non può essere modificato dal sito senza un'operazione esplicita. Per aggiornare un file .xlsm mantenendo le macro, usa il CSV e il pulsante «AGGIORNA RISULTATI FARMING» in Excel. L'esportazione .xlsx non contiene macro.

I due fogli sono quelli del file Excel esportato. La pagina non pubblica nomi, indirizzi o misurazioni nel repository.
