Importazione ed esportazione

Importa il CSV standard del registro o un CSV esportato dal foglio FARMING_STORICO del CRM Excel. Identificativi stabili impediscono importazioni duplicate. È una procedura manuale: il file Excel locale non viene aggiornato automaticamente. Esporta un CSV leggibile in Excel. Non è una sincronizzazione bidirezionale con il file Excel e nessun dato viene pubblicato su GitHub.

Per prudenza, l'importazione JSON aggiunge le attività mancanti senza eliminare l'archivio corrente. Prima di cambiare browser, esporta un backup.
