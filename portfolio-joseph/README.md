## Come aggiungere un lavoro
Aprire `lavori.json`, inserire un nuovo oggetto in `lavori`:

```json
{"title":"Nome progetto", "category":"Brochure e impaginazione", "description":"Descrizione veritiera del lavoro", "page":19, "url":"https://www.canva.com/d/LINK_VERIFICATO"}
```

I titoli iniziali sono ricavati dalle pagine 3–17 del PDF originale `Portfolio_Grafico_Joseph_Malafronte_2026_ORIGINALI.pdf` (18 pagine). Quando si aggiungono progetti nuovi, usare il link al progetto originale Canva e un numero identificativo progressivo. Non includere nel sito materiale non autorizzato alla pubblicazione.

## Note operative
- La pagina mostra la galleria caricando `lavori.json` da GitHub Pages, senza servizi a pagamento e senza dati personali dei visitatori.
- Ogni lavoro ha un link di consultazione; quando manca il link individuale verificato, il record punta al portfolio Canva generale.
- Contatto diretto volontario via WhatsApp o email.
- Il portfolio Canva completo resta la fonte di visualizzazione grafica e delle 18 pagine.
- Il PDF originale dell'autore non viene copiato nel repository da questo aggiornamento.
- Verificare periodicamente che il link Canva sia accessibile anche senza autenticazione.
